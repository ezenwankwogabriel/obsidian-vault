A successor to Amazon Q Business.
AWS Gen-AI powered assistant to help users with business tasks, software development and data analysis
	it uses FM and connects your company's documents, app, db, and the internet so employees can easily navigate resources with added context of the internet
This is built on Amazon Bedrock

You connect **Quick Index** to your companies data
Quick Index is a unified, searchable knowledge base of your companies data (fully managed RAG). It indexes company data from sources such as s3, sharepoint, onedrive, googledrive and confluence so the answers are grounded in it

Quick Research:  for deep research agent, combines internal data and the internet

Quick Flows: for simple automation built with natural language (ex: weekly report email)

Quick Automate: multi-step agentic workflows across systems, with human approvals

Quick Sight: AI powered BI dashboards, where you can ask questions about your data

Spaces: shared workspace of documents, dashboards, and agents for a team

### Amazon Q Developer
Answers question about the AWS docs and service selection.
Also about resources in your AWS account (ex: list all of my lambda functions

It doesn't implement changes to existing functions, but can provide you the steps to do them

It also gives you an AI code companion (similar to co-pilot) to help you code new apps in aws

This works with VS Code, visual studio, and jetbrains IDE

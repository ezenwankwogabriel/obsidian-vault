This is different again.

CQRS = **Command Query Responsibility Segregation**.

The basic idea:

> **Separate operations that change state from operations that read state.**

Without CQRS:

```
                 UserService
                /           \
          createUser       getUser
```

With CQRS:

```
             Application
             /          \
        Commands       Queries
           │              │
           ↓              ↓
      Write model     Read model
```

A **Command** says:

> "Do something."

Examples:

```
CreateUser
UpdateUser
CancelOrder
TransferMoney
```

A **Query** says:

> "Give me something."

Examples:

```
GetUser
GetOrder
SearchProducts
GetDashboard
```

So:

```
POST /orders
      ↓
CreateOrderCommand
      ↓
write database
```

versus:

```
GET /orders/123
      ↓
GetOrderQuery
      ↓
read database
```

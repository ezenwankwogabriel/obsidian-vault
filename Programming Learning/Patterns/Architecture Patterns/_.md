These describe code organization, dependency direction, and how systems communicates.

These aren't competitors.

You can combine them.

Imagine you're building a banking system.

At the highest level:

```
                 MICROservices
                      │
       ┌──────────────┼──────────────┐
       ↓              ↓              ↓
   Account         Payment         Identity
   Service         Service          Service
```

Inside Payment Service:

```
              Vertical Slices
                    │
       ┌────────────┼────────────┐
       ↓            ↓            ↓
  Make Payment   Refund       Get Payment
```

Inside `Make Payment`:

```
             Clean/Onion
                 │
        ┌────────┴─────────┐
        ↓                  ↓
   Application           Domain
        │
        ↓
 Infrastructure
```

And the application might use CQRS:

```
Commands
   │
   ├── MakePayment
   ├── RefundPayment
   └── CancelPayment

Queries
   │
   ├── GetPayment
   └── GetPaymentHistory
```

And services communicate through events:

```
Payment Service
      │
      │ PaymentCompleted
      ↓
   RabbitMQ
      │
      ├──→ Notification Service
      ├──→ Accounting Service
      └──→ Analytics Service
```

**All of these can coexist.**

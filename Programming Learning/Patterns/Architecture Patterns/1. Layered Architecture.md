our traditional systems such as
```
src/
├── controllers/
├── services/
├── repositories/
├── entities/
└── database/
```
for example:
```
# for example:
HTTP Request
     ↓
Controller
     ↓
Service
     ↓
Repository
     ↓
Database
```

given an ecommerce application, we'd have something like
```
controllers/
    order.controller.ts
services/
    order.service.ts
repositories/
    order.repository.ts
```
- controller handles http routing
- service handles business logic
- repository handles database access

this is easy to understand, but an issue occurs as the application grows. you end up with
```
controllers/
    user.controller.ts
    order.controller.ts
    payment.controller.ts
    product.controller.ts

services/
    user.service.ts
    order.service.ts
    payment.service.ts
    product.service.ts

repositories/
    user.repository.ts
    order.repository.ts
    payment.repository.ts
    product.repository.ts
```

A single feature is scattered across the entire application.

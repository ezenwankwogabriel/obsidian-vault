Microservices answers:

> **How do I divide the system into independently deployable services?**

For example:

```
                   API Gateway
                       │
       ┌───────────────┼───────────────┐
       ↓               ↓               ↓
   User Service    Order Service   Payment Service
       │               │               │
       ↓               ↓               ↓
   PostgreSQL      PostgreSQL       PostgreSQL
```

Each service can potentially have its own:

- codebase
- database
- deployment
- scaling
- team

And they might communicate using:

```
HTTP
gRPC
RabbitMQ
Kafka
etc.
```

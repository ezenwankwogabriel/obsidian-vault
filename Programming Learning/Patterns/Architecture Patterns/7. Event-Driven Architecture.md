This one relates directly to the RabbitMQ stuff you've been learning.

Instead of:

```
Order Service
      │
      │ HTTP
      ↓
Email Service
```

you can do:

```
Order Service
      │
      │ OrderCreated
      ↓
   RabbitMQ
      │
      ├──────────────→ Email Service
      │
      ├──────────────→ Analytics Service
      │
      └──────────────→ Notification Service
```

The producer doesn't necessarily know who consumes the event.

It says:

> "An order was created."

Other services react.

That's **event-driven architecture**.

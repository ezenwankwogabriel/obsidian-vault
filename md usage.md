Markdown (`.md`) relies on simple text formatting syntax rather than actual executable commands.

**Text Formatting & Hierarchy**

* **Headers:** Use `#` through `######` on a new line to create section headings from largest (`# Header 1`) to smallest (`###### Header 6`).
* **Bold:** Wrap text in double asterisks, like `**bold text**`.
* **Italics:** Wrap text in single asterisks or underscores, like `*italic text*` or `_italic text_`.
* **Strikethrough:** Wrap text in double tildes, like `~~strikethrough~~`.

**Lists & Organization**

* **Unordered List:** Start lines with `-`, `*`, or `+` followed by a space.
* **Ordered List:** Start lines with a number, a period, and a space (`1. First item`).
* **Task List:** Start lines with `- [ ]` for an unchecked box or `- [x]` for a checked box.
* **Blockquote:** Start a line with `>` to visually offset text or cite sources.
* **Horizontal Rule:** Place `---` or `***` on its own line to create a section divider line.

**Links, Images & Code**

* **Hyperlink:** Use `[Link Title](https://example.com)`.
* **Image:** Use `![Image Alt Text](image-url.png)`.
* **Inline Code:** Wrap text in single backticks, like ``code``.
* **Code Block:** Enclose multiple lines in triple backticks (`), optionally placing the language name directly after the opening set for syntax highlighting (e.g., `python).

**Tables**
Construct simple rows and columns using vertical bars (`|`) and hyphens (`-`):

```markdown
| Header 1 | Header 2 |
| --- | --- |
| Row 1, Cell 1 | Row 1, Cell 2 |
| Row 2, Cell 1 | Row 2, Cell 2 |

```

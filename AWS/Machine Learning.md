## Amazon Rekognition
An AWS AI Service that analyzes images and videos to identify objects, people, text, activities and other visual information

use-cases: 
	labeling
	Content moderation
	text detection
	face search & verification
	celebrity recognition, ...

After flagging sensitive content, you can do manual review using Amazon Augmented AI (A2I)

## Amazon Transcribe (speech to text)
Allows you convert speech. You pass in audio and it converts to text

## Amazon Polly (text to speech)
Turns text to speech. uses lexicon (customize pronunciation) and SSML (generate speech from plain text/documents marked up with SSML)

## Amazon Translate
To translate text. for websites, and applications

## Lex and Connect
Lex is same tech that powers Alexa. You get automatic speech recognision. It does natural language understanding to recognize the intent of text, callers

Connect: allows you to receive calls, create contact flows, cloud-based virtual contact center
No upfront payment, 80% cheaper than traditional contact center solutions

Phone call ––> Connect (receives the call) ––> Lex (streams the message for context) ––> Lambda (invokes certain action)

Amazon Comprehend
Used for NLP, a fully managed and serverless service
uses ML to find insights and relationships in text
use-case: 
	analyze customer interactions (emails)
	create/group articles by topics that comprehend will uncover

SageMaker AI
A fully managed service for developers to build ML models

Kendra
Extracts answers from within a document (text, pdf, html, ...). It indexes the files and helps for natural languge search capabilities

Personalize
To build apps with real time personalized recommendations. Same tech used by amazon.com

Textract
Extract text, handwriting and data from any scaned documents using AI and ML. data from phones, IDs, ...

This is a service for processing and analysing very large datasets using distributed data-procdessing frameworks such as Apache Spark, Hadoop, and Hive

EMR = big data processing across a cluster of machine

Imagine a company has 10 TB of application logs stored in S3 and wants to analyse user behaviour across millions of records.

Processing everything on one machine could be slow. EMR distributes the work across multiple machines, allowing them to process different portions of the dataset in parallel.

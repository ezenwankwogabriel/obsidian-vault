This brings AWS infrastructure and services into your own data center/on-premises location, so you can run AWS workloads locally while using same AWS tools and APIs

Ideally you'd have an onpremises and a cloud setup, but now AWS can give you your onpremises provisioned using AWS cloud like services

## Why use Outposts?

Imagine a factory has industrial machines that must respond in milliseconds. Sending every request to a distant AWS Region could add latency or depend too heavily on network connectivity.

With Outposts, supported compute and storage workloads can run locally, reducing the need to send every operation to the Region.

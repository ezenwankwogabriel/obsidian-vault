This is a managed AWS service for searching, analysing and visualizing large amounts of data quickly. Based on the open-source OpenSearch engine, which supports full-text search, log analytics and vector search.

In DynamoDB, you can only query by primary key or indexes
With OpenSearch, you can search any field, even partially matches
This serves as a complement to another database (analytics on a database)

## Modes
Managed Cluster
Serverless Cluster

Doesn't natively support SQL (but can using a plugin)
